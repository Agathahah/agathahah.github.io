04How I work

Four rules I don't skip.

Baseline first

Every model is compared with a simple one on the same split, so improvements are real.

Split by time

Train on the past, test on what came after. Random splits flatter models that see the future.

Gate before training

Release criteria are written first. A model that misses them is not deployed.

Show the evidence

Every number points to a repository, a test or a live demo you can open.
