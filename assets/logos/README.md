# Logo slots

The page shows a monogram badge (UNI MED, UI, PAC, DQ, BI, BRI) until a logo file exists.
Drop the official logo here with exactly these names and it appears automatically:

| File | Used for |
|---|---|
| unimed.png | Universitas Negeri Medan |
| ui.png | Universitas Indonesia (makara) |
| pacmann.png | Pacmann Academy |
| dqlab.png | DQLab |
| bins.png | Bank Indonesia Institute |
| bri.png | Bank Rakyat Indonesia |

Tips
- Square PNG, transparent background, about 256 x 256 px, under 60 KB.
- Use the logo from the institution's official website or press kit, unchanged (no recolouring or stretching).
- Logos only identify where you studied or worked; do not use them in a way that suggests the institution endorses you.
